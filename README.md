# 🚀 Featured Projects

## 🌧️ [Ethekwini Design Rainfall Engine (EDRE)](https://edre.ethekwinifews.durban/) 

**A web-based rainfall data and storm analysis application developed for engineering use.**

EDRE is an **ASP.NET Core MVC** application designed to provide engineers with access to rainfall data and tools for analysing storm events.

### Key Features
- Spatial rainfall data searching using latitude/longitude coordinates
- Interactive mapping using **Leaflet**
- Polygon-based geographic searching using GeoJSON/KML/KMZ
- Rainfall return-period and duration analysis
- CSV rainfall data processing and importing
- Storm event searching and analysis
- **PCSWMM storm file generation and export**
- User authentication and role-based access using **ASP.NET Core Identity**
- Database-driven rainfall data management using **SQL Server**
- Deployment and hosting through **Microsoft Azure**

### Technologies
`C#` `ASP.NET Core MVC` `.NET` `Entity Framework Core` `SQL Server` `Azure` `Leaflet` `JavaScript` `HTML` `CSS`

Users must register their account and accept the terms and conditions before an admin can approve it. Once approved, users will be notified by email.

**A web-based asset management and mapping system for stormwater infrastructure.**

SWAM is an application for visualising and analysing stormwater infrastructure assets and their inspection information.

### Key Features
- Interactive GIS-based asset mapping
- Spatial querying using SQL Server geometry data
- Asset inspection tracking
- Condition-based asset visualisation
- Inspection and observation reporting
- Pipe length and inspection statistics
- Dynamic map filtering and asset selection
- Integration of multiple infrastructure datasets
